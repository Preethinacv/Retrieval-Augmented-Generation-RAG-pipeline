1.This project demonstrates an End-to-End Retrieval-Augmented Generation pipeline using:

🧠 Groq's LLaMA3 for blazing-fast inference

📄 LangChain for document loading, splitting, and embedding

📦 ObjectBox as a local vector database

⚡ Streamlit for a lightweight, interactive frontend

2. Set up virtual environment
   
        python -m venv env
        source env/bin/activate

4. Install dependencies
   
      pip install -r requirements.txt

6. Add your API key
     Create.env file:
        GROQ_API_KEY=your_groq_api_key

7. Run the app  : python -m streamlit run app.py
